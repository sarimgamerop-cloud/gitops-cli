## How it Works?

GitOps-commandline uses common github commands, such as their official packages **(e.g 'git')**, and external package **(e.g 'PyGithub')**.

It includes giving the program your Personal Access Token **(PAT)**. After the setup is done, you can use a variety of simplified commands to either fetch, create, delete or even clone repositories.

---

## Setup

### Start by Cloning the repository:

```bash
git clone https://github.com/sarimgamerop-cloud/gitops-cli
cd gitops-cli
```

### Install Requirements:

```bash
pip install -r requirements.txt
```

### Run the command using **python:**

```python
python main.py
```

---

## Usage

You can now type the program commands.

Type:

```text
help
```

to get the list of commands.
