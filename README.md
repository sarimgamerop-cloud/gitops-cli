<h1 align="center">GitOps-CommandLine</h1>

Have you ever experienced the frustration of pulling the wrong repository or deleting an entire repository by **mistake**?😫 **feels horrible right**? 

GitOps-CommandLine focuses on common github commands and simplifies them into usable and understandable formats, making it easy for beginners and experienced professionals alike to simplify their daily tasks 💻

# How it Works?

GitOps-commandline uses common github commands, such as their official packages **(e.g 'git')**, and external package **(e.g 'PyGithub')**.

it includes giving the program your Personal Access Token **(PAT)**. after the setup is done, you can use a variety of simplified commands to either fetch, create, delete or even clone repositories.

# Setup:

Start by Cloning the repository:
```
git clone https://github.com/sarimgamerop-cloud/gitops-cli
cd gitops-cli
```

Install Requirements:
```
pip install -r requirements.txt
```

Run the command using **python:**
```py
python main.py
```

You can now type the program commands, type **'help'** to get the list of commands.
